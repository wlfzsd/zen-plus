# Zen.exe 内存优化方案穷举评估报告

日期：2026-10-04 ｜ 分支：upstream-chain ｜ 基线：26 小时小时级实测（logs/zen_mem_watch.csv）

---

## 一、问题定义与基线（先纠偏）

1. **"挂机不增长"已达成**：10-04 凌晨 02:21-08:21 六小时，私有内存平台稳定在 532-536MB、工作集 463-468MB，一丝未涨。用户观察到的"462MB"即任务管理器工作集的夜间平台读数。
2. **当前议题** = 总量再下探 ≥20%（本报告目标）。
3. **基线（GCPercent=40 时代，26h 实测）**：夜间平台 532-536MB；日间随流量 545-610MB（连接数 260-527）。
4. **活数据推算**：夜间 RSS≈堆（定时回收后），live ≈ 535/1.4 ≈ **380MB**。构成：规则树（54.5 万唯一网络规则 + 5.2 万唯一外观规则，17 个订阅，磁盘缓存 36MB 展开数倍）＋ Go 运行时 ＋ 传输连接池 ＋ 证书缓存（上限 5800 张 ≈ 10-15MB，certgen.go:15）。
5. 官方形态佐证：PR #388 自述启动 ~350-360MB；issue #315 报 600MB-1GB、#332 报 400-650MB。**数百 MB 是本应用的本质成本，不是泄漏。**

## 二、方案穷举（四大类 14 项）

裁决分类：【已实施】【推荐】【备选】【不推荐】【拒绝】

### A. Go 运行时层

| # | 方案 | 预期收益 | 可行性与风险分析 | 裁决 |
|---|------|---------|----------------|------|
| A1 | GOGC 40→10（堆目标=live×1.1） | 总占用 -18~22%，夜间平台 532→~420-440 | Go 文档明确语义；官方 PR #388 实测更激进的 GOGC=5 无性能问题；本应用 I/O 型负载 GC 并发无感。零行为语义变化 | **【已实施】** d3e1085（2026-10-04 17:22 安装，早于用户暂停指令，见第五章披露） |
| A2 | GOMEMLIMIT 1.5GiB→1GiB | 极端突发兜底压紧 | 仍留 ~2.5× 活数据余量，正常负载永不触顶自旋 | **【已实施】** 同上 |
| A3 | FreeOSMemory 30→10 分钟 | 闲置内存分钟级归还 OS，挂机曲线更平 | 每次 = 一次完整 GC+scavenge，毫秒级代价，10 分钟一次无感 | **【已实施】** 同上 |
| A4 | GOGC=off + GOMEMLIMIT 定值（Go 官方容器模式） | 理论同 A | 活数据 ~380MB 时 limit 需设 ≤512MiB 才有约束力，余量仅 25%，高峰垃圾冲击会触发 GC 自旋（CPU 飙升）；设 768MiB 则不比 A1-A3 好 | 【不推荐】 |
| A5 | GOGC=5（官方 #388 原值） | 比 A1 再省 ~15-20MB（→~425-435 平台） | GC 触发频率翻倍；边际收益小 | 【备选】若 A1 实测后仍想再压，改一个常量即可 |
| A6 | 动态 GC（闲时更紧/忙时放宽） | 理论上 A1 的下限+忙时性能 | 需流量探针+调参逻辑，新增复杂度与 bug 面，收益≈A1 已达成 | 【不推荐】过度工程 |
| A7 | Go 工具链升级的 GC 改进 | 微小 | 本地构建已在用 go 1.27.0 | 【已覆盖】 |

## 三、结论：哪些方案能"明显解决问题"

1. **B1 订阅裁剪（未实施，推荐，用户手动）**——唯一能进入 **250-350MB** 区间的手段，效果最大且零风险（纯取舍）。裁剪价值表（实测唯一规则数）：
   - AdGuard Spyware（d72a4d2b）：**296,324 条 ← 最大杠杆**
   - Phishing URL Blocklist：39,349 条
   - EasyList：18,044 条（AdGuard Base 内嵌它，删了几乎不亏）
   - someonewhocares hosts：13,099 条
   - URLhaus：9,588 条
   - AdGuard Base：仅 6,872 条唯一（其余全是共享，删除无收益）
2. **A1+A2+A3 组合（已实施，待验证）**——预期夜间平台 **~420-440MB（-20%）**、日间峰值 ~460-520MB。早期信号：新参数下列表装载完成后 PM 385.7MB、运行中 424.9MB（同阶段旧参数 448-469MB）。**定谳以未来数天 CSV 曲线为准**（判据：新夜间平台 ≤450MB 且日间峰值 ≤530MB = 达标）。
3. 其余 11 项方案：收益 <3% 或不可行/不值得/拒绝（理由见上表）——已穷尽，无遗漏的可实施杠杆。
